# 研究方法

## 1. 問題定義

本研究旨在根據水平井（horizontal well）的井軌跡、伽瑪射線測井訊號（Gamma Ray, GR）、已知地層接觸面，以及參考直井或型態井（typewell）的地層資訊，推估水平井各測點的真垂直厚度座標（True Vertical Thickness, TVT）。

對於每一口水平井，資料由兩部分組成：

1. 可觀測前綴：部分測點具有已知的 TVT，可用於井內校準與方法驗證。
2. 待預測後綴：後續測點的 TVT 未知，需由模型推估。

本方法不依賴測試井後綴的真實標籤，而是整合物理約束、訊號對齊、機器學習模型及井內自我驗證，建立具有局部修正能力的 TVT 軌跡。

---

## 2. 方法概述

整體預測流程由下列六個階段組成：

1. 建立 Ridge／粒子濾波器軌跡與物理選擇器軌跡。
2. 將兩類軌跡融合為初始地層對齊錨點。
3. 在標準化測深空間中進行穩健投影，以平滑地層層位。
4. 建立資料驅動的學習式軌跡，並與投影後錨點融合。
5. 使用同井地層接觸資訊進行具守門條件的局部重建。
6. 以可觀測前綴模擬遮蔽實驗，選擇或校準最終預測軌跡。

所有修正步驟均採取條件式套用：只有當可觀測資料支持該項修正時，才允許改變最終預測結果。

---

## 3. 初始軌跡建構

### 3.1 Ridge／粒子濾波器軌跡

第一類預測軌跡由 Ridge 型模型、殘差模型與粒子濾波器共同建立。

粒子濾波器將 TVT 軌跡視為隨測深演化的隱藏狀態，並利用水平井 GR 與型態井 GR 的相似程度計算觀測似然。粒子經由狀態轉移、似然加權及重採樣後，形成每個測點的 TVT 後驗分布。

為降低 GR 振幅尺度差異造成的過度自信，粒子濾波器的觀測尺度定義為：

[
\sigma_{GR}
===========

\gamma,
\operatorname{clip}(s_{\mathrm{heel}},10,60),
]

其中 (s_{\mathrm{heel}}) 為井跟可觀測區段的 GR 殘差尺度，(\gamma) 為似然寬度倍率。較大的 (\gamma) 會產生較寬的似然分布，使粒子濾波器在水平井與型態井訊號並非完全一致時保留更多候選分支。

本研究的主要實驗設定使用：

[
\gamma=1.30.
]

此外，方法亦可針對不同隨機種子及尺度執行粒子濾波器集成，以降低單次粒子抽樣造成的變異。

### 3.2 物理／訊號選擇器軌跡

第二類軌跡由訊號對齊與物理限制產生。選擇器綜合下列資訊：

* 水平井與型態井的 GR 相似度；
* 多尺度正規化互相關；
* 粒子濾波器候選軌跡；
* Beam search 候選路徑；
* 已知 TVT 前綴；
* 井軌跡的深度與幾何限制；
* 訊號殘差、自相關及候選分支穩定性。

選擇器根據每口井的局部訊號品質，選擇或融合適合的候選軌跡，而非對所有井使用完全相同的單一模型。

---

## 4. 井跟訊號校準

水平井與型態井的 GR 訊號可能存在增益與偏移差異。為降低儀器、井況或地層響應差異造成的影響，本研究利用水平井可觀測井跟區段 (H_w)，估計仿射轉換參數：

[
(\alpha_w,\beta_w)
==================

\arg\min_{\alpha,\beta}
\sum_{i\in H_w}
\left[
G_i^{hw}
--------

\left(
\alpha G^{tw}(T_i)+\beta
\right)
\right]^2,
]

其中：

* (G_i^{hw}) 為水平井 GR；
* (G^{tw}(T_i)) 為型態井在 TVT (T_i) 上的 GR；
* (\alpha_w) 為增益參數；
* (\beta_w) 為偏移參數。

校準後，水平井 GR 被轉換回近似型態井的訊號尺度：

[
\widetilde G_i^{hw}
===================

\frac{G_i^{hw}-\beta_w}{\alpha_w}.
]

此步驟可提升後續 GR 對齊、datum shift 掃描及粒子似然計算的可比較性。

---

## 5. 初始錨點融合

將 Ridge／粒子濾波器軌跡 (T_i^{ridge}) 與選擇器軌跡 (T_i^{selector}) 線性融合，形成初始錨點：

[
T_i^{A}
=======

w_rT_i^{ridge}
+
(1-w_r)T_i^{selector}.
]

本研究使用：

[
w_r=0.30.
]

因此，初始錨點主要由物理／訊號選擇器決定，Ridge／粒子濾波器軌跡則提供額外的平滑性與資料驅動資訊。

---

## 6. 地層層位投影

直接平滑 TVT 可能破壞 TVT 與井軌跡垂直位置之間的物理關係。因此，本研究先定義地層層位：

[
U_i=T_i+Z_i,
]

其中 (Z_i) 為測點的垂直座標。

對未知後綴的測深 (MD_i) 進行標準化：

[
s_i
===

\frac{MD_i-MD_{\mathrm{last}}}
{MD_{\mathrm{end}}-MD_{\mathrm{last}}},
]

並以穩健多項式函數 (f_d(s_i)) 外推地層層位：

[
\widehat U_i
============

U_{\mathrm{last}}+f_d(s_i).
]

再將預測層位轉換回 TVT：

[
\widehat T_i^{proj}
===================

\widehat U_i-Z_i.
]

最終投影軌跡由原始錨點與投影結果融合：

[
T_i^{proj}
==========

(1-\lambda_p)T_i^{A}
+
\lambda_p\widehat T_i^{proj}.
]

主要設定為：

[
\lambda_p=0.75.
]

此設計保留原始預測中的局部變化，同時抑制地層層位中不合理的高頻漂移。

---

## 7. 學習式軌跡

除物理與訊號對齊方法外，本研究另建立學習式軌跡 (T_i^{learned})。

學習式模型使用由井軌跡、GR 訊號、型態井對齊結果、粒子濾波器輸出、局部統計量及地層幾何資訊所構成的特徵。模型可由多個梯度提升模型組成，例如 LightGBM 與 CatBoost，並透過模型集成降低單一模型的偏差。

若執行環境中存在已訓練模型套件，則直接載入模型進行推論；若使用預先計算的預測檔，則必須確認：

* 預測列數與官方提交格式一致；
* ID 完全一致；
* ID 順序完全一致；
* 所有 TVT 值均為有限數值。

未通過精確 ID 對齊檢查的靜態預測檔不會被使用。

---

## 8. 投影錨點與學習式軌跡融合

投影後錨點與學習式軌跡依下式融合：

[
T_i^{blend}
===========

w_sT_i^{proj}
+
(1-w_s)T_i^{learned}.
]

主要設定為：

[
w_s=0.60.
]

此設定使最終軌跡以物理與訊號對齊結果為主，並利用機器學習模型修正其系統性殘差。

不同的 (w_s) 可作為消融實驗，但每次實驗僅改變單一融合權重，以避免多項超參數同時變動而無法辨識效果來源。

---

## 9. 雙峰分支偵測與不確定性避險

當 GR 對齊掃描出現兩個相近的局部最佳解時，表示該井可能存在兩條合理的地層對齊分支。

對候選 datum shift (\Delta)，定義截尾標準化殘差：

[
J_w(\Delta)
===========

\frac{1}{|M_w|}
\sum_{i\in M_w}
\operatorname{clip}
\left(
\frac{
\widetilde G_i^{hw}
-------------------

G^{tw}(T_i^{base}+\Delta)
}{s_w},
-6,6
\right)^2.
]

若掃描結果具有兩個具有足夠後驗質量且彼此分離的低誤差區域，則將其視為雙峰候選。

設掃描結果支持其中一個分支的機率為 (p_{\mathrm{scan}})，可觀測前綴的可信度為 (\tau_w)，則有效分支機率為：

[
p_{\mathrm{eff}}
================

\tau_wp_{\mathrm{scan}}
+
(1-\tau_w)\times0.5.
]

當前綴可信度不足時，分支機率會向 (0.5) 收縮，避免模型過度選擇單一分支。最終預測可使用兩條分支的後驗平均：

[
T_i^{hedge}
===========

p_{\mathrm{eff}}T_i^{(1)}
+
(1-p_{\mathrm{eff}})T_i^{(2)}.
]

被判定為高風險雙峰的井，亦可受到保護，避免後續校準程序對其施加幅度過大的修正。

---

## 10. 具守門條件的地層接觸重建

### 10.1 接觸面推導軌跡

對於參考地層接觸面 (c)，可由型態井的接觸面 TVT、水平井垂直位置及接觸面幾何推導候選 TVT：

[
T_i^{contact}(c)
================

## T_c^{typewell}

(Z_i-C_i)
+
b_c,
]

其中：

* (T_c^{typewell}) 為型態井中接觸面 (c) 的 TVT；
* (C_i) 為水平井位置上的接觸面垂直座標；
* (b_c) 為井別偏差修正。

偏差項由對應訓練水平井估計：

[
b_c
===

\operatorname{mean}_{j\in train}
\left[
T_j
---

\left(
T_c^{typewell}-(Z_j-C_j)
\right)
\right].
]

### 10.2 可觀測前綴守門條件

接觸面重建不會直接套用至所有井。候選軌跡必須先在該井的可觀測 TVT 前綴上接受自我驗證。

候選接觸軌跡依測深插值至測試井測點後，計算：

[
e_c
===

\operatorname{RMSE}
\left(
\operatorname{interp}*{MD}
(T^{contact}*{train},MD_i^{test}),
T_i^{input}
\right).
]

僅當下列條件成立時，才接受接觸面修正：

[
e_c<\epsilon,
\qquad
\epsilon=1.0\ \mathrm{ft},
]

並且有效比對點數達到最低門檻。

若多個接觸面均可使用，則依預先設定的地層參考優先順序逐一測試，並選擇前綴誤差最低且通過門檻的參考面。

通過守門條件後，僅替換位於訓練井測深支撐範圍內的未知測點；若守門條件失敗，則保留原有融合軌跡。

---

## 11. 可觀測前綴校準

### 11.1 模擬遮蔽驗證

由於測試井提供部分已知 TVT，本研究利用該前綴建立井內模擬驗證。

對每一口井，依不同切割比例暫時隱藏已知前綴的後段，例如：

[
r\in{0.50,0.65,0.75}.
]

前段資料作為模型輸入，後段資料作為偽未知驗證集。對候選方法 (k)，計算：

[
e_{w,k}
=======

\operatorname{RMSE}
\left(
T_{w,k}^{candidate},
T_w^{input}
\right)
]

，其中誤差僅在被暫時隱藏的前綴測點上計算。

### 11.2 候選軌跡

候選集合可包括：

* 原始融合錨點；
* 穩健多項式外推；
* 地層曲面或接觸面重建；
* 粒子濾波器候選；
* 不同融合與平滑強度的軌跡；
* 受限幅度的候選修正。

不同切割比例與隨機種子所得的驗證結果會被彙整，以降低單一切割點造成的偶然性。

### 11.3 校準策略

本研究定義三種校準強度：

* conservative：僅允許小幅度且高可信度的修正；
* balanced：在驗證誤差改善與軌跡穩定性之間取得平衡；
* aggressive：允許較大幅度採用驗證表現最佳的候選。

若使用錨點模式，最終軌跡保持為：

[
T^{final}
=========

T^{self\text{-}verified\ anchor}.
]

若使用可觀測前綴模式，則最終軌跡為：

[
T^{final}
=========

T^{vp}_{profile},
]

其中 (profile) 表示選定的校準強度。

為避免可觀測前綴校準破壞已通過驗證的接觸面結果，接觸守門程序會在前綴校準完成後再次執行。

---

## 12. 模型套件的受限修正

當外部模型套件的預測與現有最終軌跡存在系統性差異時，可將該差異視為額外修正訊號。

然而，模型套件不直接取代主要軌跡，而是根據訊號強度、前綴驗證結果及最大權重限制進行門控融合。其一般形式可表示為：

[
T_i^{pkg}
=========

T_i^{base}
+
g_w,
\delta_i^{pkg},
]

其中：

* (\delta_i^{pkg}) 為模型套件與基準軌跡之差；
* (g_w) 為井別門控權重；
* (g_w) 受到預設最大值限制。

此設計使外部模型僅能提供微量修正，不能在缺乏井內證據時大幅改變預測。

## 13. 競賽前沿局部實驗

除核心方法外，notebook 另包含一項局部前沿實驗。該實驗只針對已由先前控制實驗支持的粒子濾波器分支，進行固定幅度的延伸修正。

該修正的總分支位移為：

[
2.522\ \mathrm{ft},
]

其中新增的局部延伸量為：

[
0.522\ \mathrm{ft}.
]

此數值來自先前 2 ft 與 3 ft 控制點之間的內插假設，屬於預先指定的反應曲線假說，而非由該 notebook 自身的未知排行榜成績反向調整所得。

為避免局部實驗污染其他結果，修正交易必須驗證：

* 來源 submission 的雜湊值；
* 目標井識別；
* 目標列數；
* 預期分支；
* 實際移動幅度；
* 非目標列保持不變。

因此，此步驟應被視為競賽實驗附錄，而非一般化方法的必要組成。

## 14. 輸出驗證與可重現性

最終輸出必須符合官方提交資料契約。驗證項目包括：

1. 欄位名稱必須為 `id` 與 `tvt`。
2. 列數必須與範例提交一致。
3. ID 必須唯一。
4. ID 順序必須與範例提交完全一致。
5. 所有 TVT 必須為有限數值。
6. 寫入後重新讀取並驗證。
7. 計算檔案 SHA-256 雜湊值。
8. 保留最後一份通過驗證的提交檔與稽核紀錄。

主要輸出包括：

* 最終 TVT 預測；
* 投影後錨點軌跡；
* 學習式軌跡；
* 融合權重比較；
* 接觸面修正決策；
* 可觀測前綴校準結果；
* 雙峰分支偵測結果；
* 模型套件修正紀錄；
* 提交檔完整性與雜湊稽核。

## 15. 視覺化分析

視覺化程序在最終提交完成後執行，並以唯讀方式載入各階段輸出，避免圖表生成改變預測檔。

主要視覺化包括：

1. 軌跡比較圖：比較投影錨點、學習式軌跡與最終軌跡。
2. 分支不確定性圖：呈現粒子後驗質量、候選中心及分支間距。
3. 平面井軌跡圖：依最終 TVT 對水平井空間位置著色。
4. 輸出完整性儀表板：呈現檔案雜湊、列數、ID 一致性及非目標資料未變更的證據。

繪圖前後均重新計算最終提交檔雜湊，確認視覺化程序未修改提交結果。

## 16. 評估方法

本方法主要使用可觀測前綴上的均方根誤差作為井內評估指標：

[
\operatorname{RMSE}
===================

\sqrt{
\frac{1}{n}
\sum_{i=1}^{n}
(\widehat T_i-T_i)^2
}.
]

評估分為三個層次：

1. 局部模型評估：比較粒子濾波器、選擇器、投影模型及學習模型。
2. 井內模擬遮蔽評估：以已知前綴的後段模擬未知區域。
3. 外部競賽評估：使用公開排行榜分數檢驗整體預測表現。

公開排行榜分數僅用於比較完整提交，不應被解讀為個別修正層的直接因果效果。若某個 notebook 尚未取得自身的完整評分結果，則其分數效果應標示為未確認。

---

## 17. 消融實驗設計

為識別各方法元件的貢獻，可分別測試：

* 不使用地層層位投影；
* 改變錨點與學習式軌跡的融合權重；
* 不使用接觸面守門修正；
* 不使用可觀測前綴校準；
* 不使用雙峰分支保護；
* 不使用模型套件修正；
* 改變粒子濾波器似然尺度；
* 改變前綴切割比例；
* 比較 conservative、balanced 與 aggressive 校準策略。

為保持實驗可解釋性，每個變體原則上只改變一項主要設定。

---

## 18. 方法限制

本方法具有下列限制：

1. 型態井依賴：若型態井與水平井的地層或 GR 響應差異過大，訊號對齊可能失效。
2. 前綴代表性：可觀測前綴未必能代表更深部或更遠端的未知後綴。
3. 接觸面誤差：地層接觸面資料若存在系統性偏差，可能產生錯誤重建。
4. 分支不可識別性：當兩條地層分支在可觀測前綴上表現相近時，無法保證選出真實分支。
5. 模型套件依賴：學習式預測可能受訓練資料分布及預訓練模型版本影響。
6. 局部排行榜實驗的泛化性有限：固定井、固定分支及固定偏移量的修正不應視為可泛化至其他資料集的通用方法。
7. 多階段流程可能累積偏差：即使每個局部修正均通過自身驗證，階段間交互作用仍可能影響最終結果。

---

## 19. 方法總結

本研究提出一套接觸面守門式地層對齊方法。其核心思想是先以物理與訊號模型建立穩健錨點，再利用機器學習模型補充資料驅動資訊，最後透過可觀測前綴與同井地層接觸資訊進行局部自我驗證。

相較於無條件套用單一模型，本方法將每個修正層設計為受證據約束的條件式操作。只有當井內可觀測資料支持候選修正時，該修正才會進入最終軌跡，從而在預測精度、物理合理性與輸出可稽核性之間取得平衡。
